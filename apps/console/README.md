# @cs/console — 管理后台（P2 占位）

> 状态：未初始化。本目录用于占位，说明 P2 阶段的模块划分与选型，避免现在过度建设。

## 规划范围（对应手册 2.4 FED 四件套之二）

| 模块 | 功能 | 选型 |
| --- | --- | --- |
| 渠道配置 | 网页 / 微信 / APP 渠道开通与嵌入代码 | React + Ant Design 5 |
| 知识库 | FAQ / 文档上传、切片策略、权限隔离 | React + 上传组件 + 表格 |
| 流程画布 | 拖拽编排引导流程（退货、催发货等） | ReactFlow / LogicFlow |
| 数据看板 | 拦截率、FRT、转人工率、质检报表 | ECharts 5 |
| 机器人配置 | 人设 Prompt、欢迎语、兜底话术 | 表单 + 模板库 |
| 成员权限 | 租户 / 角色 / RBAC | amis 或自研 + ruoyi 体系 |

## 工程约定

- 微前端拆分（qiankun）：渠道、知识库、画布、看板各自独立开发部署；
- 与 `packages/protocol` 共用消息协议，不自定义私有消息格式；
- P2 启动条件：P1 MVP（挂件 + 网关）稳定运行，且已有 1 个种子客户提出配置诉求。
