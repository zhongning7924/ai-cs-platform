# ADR-0011：转人工（最小闭环）

- 状态：已采纳
- 日期：2026-10-26
- 关联：ADR-0006（智能体架构护栏）、ADR-0009（数据面）

## 背景

`bot.ts` 里一直有一句「正在为您转接人工客服，当前排队 1 位，预计等待 30 秒」。

这句话是假的：没有工单、没有队列、没有坐席，用户等下去也不会有任何人出现。它比直接说「我不知道」更糟——**用户信了，然后被晾着**。

这是转人工必须补上的真实理由：不是「缺个高级功能」，而是补掉一句谎话，给兜不住的问题一个出口。

## 决策

### 1. 触发只用规则，不上模型判断

三类触发：

| 类型 | 判据 |
|---|---|
| `sensitive` | 命中 12315 / 起诉 / 曝光 / 赔偿 / 退款没到 等升级表述 |
| `user_request` | 命中 人工 / 真人 / 找人 / 投诉 / 举报 / 差评 |
| `low_confidence` | 后端自报 `degraded`，或回答命中兜底话术 |

理由：
- 转人工是兜底路径，**必须 100% 可预测**。模型抽风时恰恰是最需要它稳定的时刻。
- 用户说「转人工」就必须转，不能被模型劝回去继续聊。
- 规则误判的代价是「多转一次」；模型误判的代价是「该转没转，客户炸了」。

**顺序上敏感优先。** 「不解决我就打 12315 投诉」两条都命中，但它是升级场景，标成「用户主动要求」会让主管漏掉最该看的那单。

### 2. 工单是唯一事实来源，会话上不存 mode

不在 `Session` 上加 `mode: 'ai' | 'queued' | 'active'`，而是每次问 `handoffStore.openBySession(sessionId)`。

两份状态一旦不同步，就会出现「界面显示已接入、后端还在调模型」这类最难复现的 bug。当前是否人工模式，只认工单里有没有未关闭的单。

### 3. 人工期间不调模型

用户在人工阶段发的每一条消息，原样进工单，一个字都不经过模型。

否则坐席和机器人会同时在对话框里说话，用户会以为系统坏了。实测该路径 275ms 返回（只写工单，不调 LLM）。

### 4. 建单在回答之前完成

「正在为您转接，当前排队第 N 位」这句话必须**在工单已存在之后**才说得出口。先答再转的写法只能编一个位次，又回到假话。

### 5. 用户端用轮询，不用 WebSocket

坐席的回复可能在 30 秒后，也可能在 5 分钟后。为不确定的时刻挂一条长连接，弱网下必然断，断了还要重连重放。

`GET /api/chat/poll?sessionId&afterSeq` 每 1.5s 拉一次、增量返回，断线自愈，实现十几行。单商户并发量不值得为它上 WebSocket。

轮询的防越权靠 `sessionId` 本身不可猜（`sess_` + 时间戳 + 随机后缀），和现有的会话能力模型一致。

### 6. 关闭即回 AI

`openBySession` 只认未关闭的工单，所以坐席点「已解决」后，同一 sessionId 的下一条消息自动回到智能体，不需要额外通知。

### 7. 事件溯源 + 重启重放

工单每次状态变化都追加到 `var/data/handoff.jsonl`（`ticket` / `message` / `status` 三类记录），启动时重放恢复。

用户不会因为运维重启就「排队排丢了」——这是客服系统里最容易变成投诉的运维动作。

落盘前脱敏（手机/身份证/邮箱），但**保留订单号**：它是回查的主键。

## 坐席台

单文件 `public/console.html`，零构建，`/console` 直接访问。客户运维不需要 Node 工具链。

坐席可以：看队列（含转接原因、等待时长、最后一句）、接入、看 AI 阶段前情、回复、按结果关闭（已解决/未解决/用户离开）。

## 后果

- 转人工率、平均等待、平均处理时长可以算了（`/api/handoff/queue` 的 stats），但**转人工率的分母在 traceStore 里**，两者还没打通，目前 `handoffRate` 恒为 null。
- 工单数据与对话记录分离：`TRACE_STORE_ENABLED=false` 关掉的是数据采集，不影响转人工——工单是业务功能，不是分析素材。

## 已知限制（MVP 边界）

1. **单实例**：工单状态靠内存 + JSONL 重放。多实例会出现「A 机器接了、B 机器还在排队」。
2. **抢单制，不自动分配**：没有坐席技能、在线状态、负载均衡。
3. **没有排队超时兜底**：坐席全离线时，用户只能一直等，没有「当前非工作时间」的降级提示。
4. **坐席关页不会自动关单**：未结束的单会一直挂在「接待中」，只能手点「用户离开」。
5. **没有转回后的质检**：人工会话结束后，坐席的回复不进入任何评测流程。
